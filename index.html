Warehouse-Wide Data Quality Framework

Designed and built a monitoring layer that runs checks at ingestion across every source in the warehouse and writes results to a central logging schema. Row-count reconciliation against source, null and type violations, referential breaks and freshness thresholds are recorded per table per run, so a broken feed is caught as a logged failure rather than discovered by a manager reading a wrong number three days later. Now the group's single source of truth for data integrity, and the reason reporting can be trusted without manual reconciliation.

Automated Warehouse Deployment — DACPAC & GitHub Actions

Warehouse schema is defined in source control and deployed automatically. A merge triggers a GitHub Actions workflow that builds a DACPAC from the database project and publishes it to the target warehouse, so schema changes move through environments the same way application code does — reviewed in a pull request, versioned, and repeatable. Removed the class of failure where a change works in development because someone remembered to run a script by hand, and made every deployment auditable.
