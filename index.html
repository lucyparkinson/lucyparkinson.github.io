PMS Migration — New Source System into an Existing Warehouse Model

Leading the migration of the group's new property management system into a dimensional model built around the platform it replaces, so reporting stays continuous across both. I ran a warehouse inventory to scope it — 56 target tables — then split the work into slices owned end to end and set the standards the team builds to: a routing rule for new versus existing load procedures, merge deletes scoped by source system so the retired platform's history can't be wiped, and a defined rule for columns with no equivalent in the new source. The vendor's bronze layer turned out to be parquet files rather than queryable tables, so I built a control-driven parquet-to-Delta step — five modules, 144 entity loads — scheduled behind their nightly extract with failure alerts. When their engineers came off the project, I brought the outstanding scope into environments my team could reach rather than let it stall.

Automated Warehouse Deployment — DACPAC & GitHub Actions

Warehouse schema is defined in source control and deployed automatically. A merge triggers a GitHub Actions workflow that builds a DACPAC from the database project and publishes it to the target warehouse, so schema changes move through dev, test and production the same way application code does — reviewed in a pull request, versioned and repeatable, with environment-specific references resolved at deploy time rather than hard-coded per environment. I maintain the shared workflow repository these deployments run through, and I'm the person who diagnoses and fixes the build failures when they happen.

What Keeps You Up — Narrative Data Poster

Winner · Unique Perspective Award

An A4 poster built entirely in Power BI for the Fabric Community's Halloween data challenge, from the organisers' survey of 105 people in the data community: what scared them as children, and what scares them now. I modelled the responses as a star schema — fear, country, gender and age-group dimensions over a response fact — rather than charting the survey flat, then built the piece around two findings. Thirty-six of the 43 children who feared something spooky have grown out of it, while those who feared other people are twice as likely to still fear them as everyone else, 63% against 30%. And the share naming a global threat climbs with how late someone answered: 18% in the morning against 38% between 10pm and midnight, which meant deriving each respondent's local answer time from their country before the comparison was possible. The after-midnight group is reported as four of five rather than 80%, because five people isn't a percentage. Ghost and clock marks are one respondent each, drawn in Deneb (Vega-Lite) alongside native visuals, with the light-to-dark split carrying the narrative down the page.
